# Electric Vehicle Market Performance & Insights

A responsive starter website for the SkillWallet / Tableau EV market analytics project.

## Files
- `index.html` — the website. It works by opening it in a browser.
- This is a starter template: sample chart values are illustrative, not real market results. Replace placeholders with your verified dataset findings.

## Publish as a free live website with GitHub Pages
1. Sign in to https://github.com/ and create a new **public** repository, for example `ev-market-insights`.
2. Upload `index.html` to the repository's root folder. You can also upload this README.
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub Pages will display your live website URL on the Pages screen, usually:
   `https://YOUR-USERNAME.github.io/ev-market-insights/`

## Publish your Tableau dashboard
1. Open your workbook in Tableau Public or Tableau Desktop.
2. Sign in to Tableau Public and choose **Save to Tableau Public** (menu wording can vary).
3. Publish the workbook and open it on your Tableau Public profile.
4. Copy the published workbook URL. Use the actual published link in your SkillWallet project.

## Links to submit
